## 6. 🔐 AI ChatBot Application

### Description

A Python-based conversational chatbot that processes user queries and provides appropriate responses using basic Natural Language Processing techniques.

### Features

- Interactive chat interface
- Responds to common user queries
- Greeting responses
- Python-related responses
- AI and chatbot information
- Multiple responses for the same query
- Case-insensitive input processing
- Exit commands such as `bye`, `stop`, `exit`, and `quit`

### Technologies Used

- Python
- Object-Oriented Programming
- Basic NLP
- `random`

### Key Concepts

- Classes and Objects
- Dictionaries
- Functions
- String processing
- Keyword matching
- Random response generation
- User input handling

### Run the Project

python chatbot.py
