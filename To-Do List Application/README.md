## 2. 🔐 To-Do List Application

### Description
A command-line To-Do List application that allows users to manage their daily tasks.

### Features
- Add new tasks
- View existing tasks
- Mark tasks as completed
- Delete tasks
- Save tasks to a JSON file
- Load saved tasks when the application starts

### Technologies Used
- Python
- JSON
- File Handling
  
### Key Concepts
- Lists and dictionaries
- Functions
- CRUD operations
- File handling
- JSON data storage
- Exception handling
  
### Run the Project
python todo.py
