## 5. 🔐 Expense Tracker System

### Description
An Expense Tracker application that allows users to record, categorize, and analyze their daily expenses.

### Features
- Add expenses
- Record date, category, description, and amount
- View all expenses
- Categorize expenses
- Generate spending summaries
- Generate monthly reports
- Store records in CSV format
  
### Technologies Used
- Python
- CSV
- datetime
- File Handling

### Key Concepts
- Functions
- Dictionaries
- CSV file handling
- Data processing
- Date validation
- Expense calculations
- Monthly reporting
  
### Run the Project
python expense_tracker.py
